## 🌟 主な機能・特徴

- 🎮 **画面認識による自動勝敗検知**
  - ゲーム終了時の勝利（VICTORY）や敗北（DEFEAT）を画面から自動検出して即座にカウント。
  - サブモニターでゲームを起動していても自動認識する「画面自動追従」に対応。
- 📺 **OBS Studio 完全リアルタイム連携**
  - ブラウザソース（`http://127.0.0.1:8080/counter`）を貼り付けるだけで、カウント時に弾むアニメーション付きで同期表示。
  - **4種類の洗練されたスキン**（すりガラス / シンプル / チケット風 / バッジ型）を搭載。
  - 直感的なカラーピッカーで、配信画面のテーマカラーに合わせて自由にカスタマイズ可能。
- ⌨️ **安心のグローバルショートカットキー**
  - ゲーム画面が最前面のままでも、キー入力（初期設定: F7/F8）で手動介入・取り消し（Undo）・リセットが可能。
- 🌿 **目に優しいナチュラルグリーン UI**
  - CustomTkinterを採用したモダンで親しみやすい管理画面。ライトモード／ダークモードを瞬時に切り替え可能。
- 🔄 **リアルタイム・ヘルプ更新**
  - `help_content.json` を編集・保存するだけで、アプリを起動したまま画面上のFAQやお知らせを即時反映。

## 💻 動作環境

- **OS**: Windows 10 / 11 (64bit)
- **Python**: 3.10 以上
- **対応ゲーム**: Overwatch 2（※今後マルチタイトル拡張予定）

## 🚀 クイックスタート

### 1. リポジトリのクローン・ダウンロード
```bash
git clone https://github.com/<あなたのユーザー名>/peko-score.git
cd peko-score
```

### 2. 必要なライブラリのインストール
```bash
pip install -r requirements.txt
```

### 3. アプリの起動
```bash
python app.py
```
*(または `run_pekoscore.bat` をダブルクリックして起動できます)*

## 📺 OBS Studio への配置手順

1. ぺこすこあ を起動し、左サイドバー下の **「ブラウザソース用URLコピー」** をクリックします。
2. OBS Studio のソース追加で **「ブラウザ」** を選択します。
3. URL欄に `http://127.0.0.1:8080/counter` を貼り付けます。
4. 幅: `600` / 高さ: `160`（お好みのサイズ）に設定します。
